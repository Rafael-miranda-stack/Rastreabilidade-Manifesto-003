# 📦 Rastreabilidade - Manifesto 003

Aplicação Streamlit para controle de lotes e validades integrada com Omie ERP.

## 🎯 Funcionalidades

- Sincronização automática de lotes/validades via Google Apps Script
- Consulta de remessas no Omie ERP
- Busca de lote/validade no Neon Database
- Interface Streamlit para faturamento

## 🛠 Tech Stack

- **Streamlit** - Interface
- **Omie ERP** - API de remessas
- **Neon Database** - Banco de dados
- **Google Apps Script** - Sincronização
- **Render** - Deploy

## 🚀 Como usar

1. Clone o repositório
2. Configure `.streamlit/secrets.toml`
3. Instale: `pip install -r requirements.txt`
4. Execute: `streamlit run app.py`
